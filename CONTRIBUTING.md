# Contribuciones

1. Abre un issue con el comportamiento esperado y el observado.
2. Usa únicamente datos ficticios. Elimina nombres, RUT y antecedentes de clientes de archivos, capturas y registros.
3. Trabaja en una rama y realiza cambios acotados.
4. Ejecuta `python -m unittest discover -s tests -v` y genera el ejemplo.
5. Si cambia la presentación, inspecciona el PDF y el HTML.
6. Si cambia una referencia normativa, enlaza la fuente oficial y explica su alcance. No añadas predicciones de duración sin evidencia.

No se aceptan cambios que eludan controles de acceso de la OJV. Las mejoras de consulta automática requieren un diseño y una revisión separados.
